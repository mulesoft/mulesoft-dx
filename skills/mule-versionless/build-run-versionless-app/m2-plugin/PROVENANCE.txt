----------------------------------------------------------------------
Refreshing a module
----------------------------------------------------------------------
1. In the mule-maven-plugin checkout, on branch
   chore/versionless-mule-project-support, build the module:
     mvn -q -pl <module> -am install -DskipTests
   (install, not just package — setup.sh resolves these from ~/.m2.)
2. Copy the produced jar/pom over the one here, preserving the
   org/mule/tools/maven/<module>/4.11.0-SNAPSHOT/ path.
3. Re-run the build-run-versionless-app verify loop (setup.sh ->
   build the bundled example-app) before committing.
4. Update this file: sha256 (shasum -a 256 | cut -c1-12), size,
   branch, commit (git rev-parse HEAD), build date, and — for a
   behavioural change — the carries: block.
